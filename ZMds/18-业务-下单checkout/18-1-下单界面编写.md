### 第 4 步：商品详情 "立刻下单"

控制器

lib/pages/goods/product_details/controller.dart

```dart
  // 立刻购买 checkout
  void onCheckoutTap() async {
    // 检查是否登录
    if (!await UserService.to.checkIsLogin()) {
      return;
    }

    // 检查空
    if (product == null || product?.id == null) {
      Loading.error("product is empty");
      return;
    }

    // 立刻购买 checkout
    BottomSheetWidget.show(
      context: Get.context!,
      // titleString: "支付确认",
      content: BuyNowPage(product: product!),
    );
  }
```

> `BottomSheetWidget.show` 采用底部弹出视图的方式展示
